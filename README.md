# JML website

Static experiment results for the John Mitchell Lab.

The experiment selector includes the existing Experiments 2–5, coordination mechanism results from June 2026, and Experiment 6 belief elicitation results from August 2026.

The new donation results pages include interactive county maps, searchable county and state tables, and aggregate CSV downloads. Donation amounts describe gift-card donation choices reported in the survey.

Raw survey exports, analysis scripts, publishing instructions, and site administration links are maintained outside this public repository.
